# Documentación técnica

- `DOCUMENTACION_V2.docx` — documento técnico completo: cómo funciona el sistema, por qué se tomó cada decisión de arquitectura y el plan de sprints.
- [`DESPLIEGUE.md`](DESPLIEGUE.md) — cómo levantar el sistema completo en un servidor.
- `bruno-collection/` — peticiones listas para probar la API con [Bruno](https://www.usebruno.com/). Corre primero "Registro profesor" o "Login": guardan los tokens que usan las demás.
- Diagramas: ver los enlaces a Lucidchart y los archivos `.drawio` de la sección 3.1 del documento técnico. Conviene exportarlos aquí también en cuanto haya una versión estable, como respaldo del enlace externo.

El estado actual del proyecto, cómo levantarlo y la lista de endpoints están en el [README principal](../README.md).

A medida que se tomen decisiones técnicas nuevas, conviene actualizar el documento técnico (en particular la Parte 2, "Por qué estas decisiones") en lugar de dejar que la justificación viva solo en mensajes de chat.
